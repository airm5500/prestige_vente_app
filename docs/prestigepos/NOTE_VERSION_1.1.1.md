# PrestigePOS 1.1.1 (versionCode 3)

Version de PrestigePOS construite avec Prestige Mobile **4.3.1+17** (code partagé). Rien ne change dans la borne
ni dans les écrans propres à PrestigePOS : la nouveauté de la 4.3.1 (D18, boîte déjà scannée refusée) concerne la
réception des BL de Prestige Mobile, qui n'est pas dans PrestigePOS. Le journal HTTP masque désormais le champ
`serie` (code commun).

Inchangé depuis la 1.1.0 : démarrage automatique avec l'appareil, « Revenir à Android », message « Ajouté » en haut
de l'écran de la borne. Prestige Mobile reste identique à sa version de référence (job `prestige-mobile-identique`,
référence 4.3.1+17).
