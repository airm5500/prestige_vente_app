Écran de lancement et écran de connexion : 3 propositions

Maquettes à taille réelle d'un téléphone (360 × 800) et d'une tablette en paysage. Toutes les propositions gardent la même logique qu'aujourd'hui (réglages, licence, borne, connexion automatique « Rester connecté », connexion au serveur) : seule la présentation change, et l'écran d'origine reste disponible derrière l'interrupteur « Nouvelle interface ». Charte reprise des écrans déjà refaits : bleu Prestige #003366, ambre #F59E0B pour l'action principale, coins arrondis, cibles tactiles d'au moins 48 px.

Nom de l'officine affiché à titre d'exemple : « Pharmacie Les Palmiers » (en réalité, le nom reçu du serveur à la dernière connexion, gardé sur l'appareil). Logo : icône actuelle de l'application.

A · Sobre professionnelB · Pharmacie moderneC · Express comptoirRecommandation : A, avec l'option « derniers utilisateurs » de C pour les terminaux de comptoir

A · Sobre professionnel — lancement

Fond bleu nuit, logo centré, barre de progression avec les vraies étapes du démarrage. Les étapes apparaissent seulement si le démarrage dure plus d'une demi-seconde (plus d'attente forcée de 2 s).

A · Lancement — cas particuliers (mêmes règles pour B et C)

Aujourd'hui : boîte de dialogue « Configuration / Réessayer » si le serveur ne répond pas, écran d'enregistrement de licence si elle est absente ou expirée, Configuration si l'appareil n'est pas configuré, ouverture directe de la borne si le mode borne est actif. La proposition affiche ces cas sur l'écran de lancement lui-même, avec un message clair et l'action utile.

A · Sobre professionnel — connexion

En-tête bleu avec le logo, l'officine et l'état du serveur (remplace l'interrupteur Local / Distant et la roue dentée de la barre du haut). Formulaire blanc, gros bouton ambre.

A · Changer de serveur — protégé par le code PIN administrateur

Aujourd'hui, l'interrupteur Local / Distant et la roue dentée sont accessibles à tous depuis l'écran de connexion. Proposition : un seul bouton « Changer », qui demande le code PIN administrateur déjà existant (Paramètres › Sécurité), puis propose les serveurs enregistrés avec leur état.

A · Aperçu tablette en paysage — proposition recommandée

B · Pharmacie moderne — lancement et connexion

Croix verte de pharmacie, dégradé doux vert d'eau / bleu clair, carte de connexion « flottante ». Plus chaleureux, plus « officine » ; le vert remplace l'ambre pour le bouton principal.

C · Express comptoir — lancement et connexion

Pensée pour les terminaux Sunmi partagés au comptoir : on touche son nom parmi les derniers utilisateurs de l'appareil, puis on tape son mot de passe ou un code PIN personnel. Gros boutons, lisible à bout de bras, aucune saisie d'identifiant.

Ces maquettes sont des propositions : aucun écran de l'application n'est modifié. Détails, recommandation et questions : docs/PROPOSITIONS_LANCEMENT_CONNEXION.md.
