Ventes : propositions de présentation

Maquettes des écrans proposés pour Pré-vente / Vente, Pré-vente Assurance et Vente Carnet. Couleurs et composants identiques aux menus déjà refaits (Réception BL, Pointage…). Montants fictifs.

1. Pré-vente / Vente — les 3 présentations

Un seul panier ; le choix « prévente » ou « vente » se fait à la fin (bouton du bas).

2. Encaissement sur une seule page

Remplace la suite de dialogues (mode → espèces → confirmation → impression).

3. Pré-vente Assurance

Étapes Client → Couverture → Produits → Encaissement ; carte client toujours visible ; net recalculé automatiquement.

4. Vente Carnet

Le client est son propre ayant droit par défaut ; on peut en choisir un autre ou en créer un.

5. Liste des préventes et sécurités

Tous les écrans existent en A (tableau de bord), B (compact) et C (guidé), au choix dans le menu « Présentation », comme les autres menus.
